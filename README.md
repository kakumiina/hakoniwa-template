# 箱庭テンプレート（hakoniwa-template）

夜の島に浮かぶ、3階建ての書庫と小さな街の 3D 箱庭です。
自分の Markdown を本棚に並べて、キャラクターと一緒に歩いて読めます。
ブラウザだけで動き、サーバーもビルドも要りません。

- 3D 描画は [three.js](https://threejs.org/) r128（cdnjs から読み込み。初回はインターネット接続が必要です）
- 画像・音声ファイルは使っていません。建物・キャラクター・BGM はすべてコードで生成しています

## 起動方法

どちらでも動きます。

1. **そのまま開く**: `index.html` をブラウザ（Chrome / Edge / Safari / Firefox）にドラッグする（`file://` で開けます）
2. **ローカルサーバーで開く**:
   ```sh
   python3 -m http.server 8000
   ```
   を実行して、`http://localhost:8000/` を開く

スマホでは画面下の十字パッドで歩けます。2本指でドラッグすると回転、ピンチで拡大縮小します。

## 操作キー

| キー | 動作 |
|---|---|
| `W` `A` `S` `D` ／ `↑` `↓` `←` `→` | 歩く（らせん階段は ↑ 上る ↓ 下りる） |
| `Shift` | 走る |
| `E` ／ `Space` ／ `Enter` | 本棚を開く・建物を見る・アクション |
| `1` `2` `3` | アクションが複数あるときに選ぶ |
| `/` | 本を探す（全文検索。ヒットした棚に光の柱が立つ） |
| `T` | ワープ（行き先を選ぶと戸口の前へ） |
| `V` | 鑑賞モード（キャラクターが島を気ままに巡る。カメラは「追う／固定」を切り替え可） |
| `C` | 着替え（服・髪型） |
| `M` | BGM のオン／オフ（Web Audio でその場で生成） |
| `U` | 表示を消す（右下の丸ボタンで戻す） |
| `I` | 操作説明をたたむ／開く |
| `Q` `R` ／ ドラッグ | 横に回す |
| `F` `G` | 縦に回す |
| `O` | 自動でゆっくり回す |
| `H` | 基本視点に戻る |
| ホイール | 拡大縮小 |
| `Esc` | 閉じる |

本の背表紙をクリックしても読めます。

## 名前を変える（CONFIG）

`index.html` の `<body>` のすぐ下に CONFIG があります。

```js
window.HAKONIWA_CONFIG = {
  aiName: 'AI',                       // 島に住む案内役の名前
  ownerName: 'あなた',                 // 見に来る人（持ち主）の呼び方
  owlName: 'フクロウ',                 // いつも一緒にいるフクロウ
  catNames: ['猫A', '猫B', '猫C'],     // 家の猫3匹
  townName: '灯りの街',                // 橋の向こうの島
  title: '{AI}の書庫'                  // 画面左上と書庫の看板
};
```

セリフ・看板・本文の中では、次の書き方がこの値に置きかわります。

| 書き方 | 置きかわる値 |
|---|---|
| `{AI}` | aiName |
| `{YOU}` | ownerName |
| `{OWL}` | owlName |
| `{CAT0}` `{CAT1}` `{CAT2}` | catNames の1〜3番目 |
| `{TOWN}` | townName |
| `{time}` | 今の時刻（セリフだけ） |

## セリフを足す（lines.js）

`lines.js` に書いたセリフは、本体のセリフ表に「足される」だけです（無くても動きます）。
場所・動作ごとの表（`LINES` / `COZY`）、時間帯（`TIME`）、曜日（`WEEKDAY`）、月（`MONTH`）、四季の庭（`GARDEN`）があります。
セリフの頭に `[sit:sofa]` のような札を付けると、その条件のときだけ話します。札の一覧は `lines.js` の冒頭にあります。

## 本を作る（books/ → data.js）

```
books/
  01-島の案内/
    island-guide.md
    ...
  02-星と海/
    ...
```

- `books/` の中のフォルダ1つが本棚1架、その中の `.md` 1つが本1冊です。フォルダ名の頭の番号（`01-`）は並び順にだけ使われます。
- 本の頭に front matter を書けます（省略可）。

  ```markdown
  ---
  title: 本のタイトル
  type: reference   # hub / user / feedback / project / reference / other（背表紙の色）
  ---
  ```

- 本文で `[[別の本のファイル名]]` と書くと、本どうしがつながり、読んでいる間は夜空に金の線で結ばれます。

本を書き足したら、次を実行して `data.js` を作り直してください（Python 3 だけで動きます）。

```sh
python3 build_data.py
```

書庫には 20 架ぶんの本棚があります。棚が足りないときは空の棚が並び、多すぎる分は表示されません。1 架に置けるのは 40 冊までで、超えた分は次の棚に分かれます。

## URL で変えられること

| 指定 | 内容 |
|---|---|
| `?hd2d=0` ／ `?hd2d=lite` ／ `?hd2d=1` | 光の仕上げ（HD-2D風）をオフ／軽量／フル。指定なしは PC=フル、タッチ端末=軽量 |
| `?month=4` | 四季の庭の季節を月で指定（指定なしは日本時間の今の月） |
| `?watch=1` | 開いたときから鑑賞モード |
| `?cam=fixed` | 鑑賞中のカメラを固定に |

## ファイル構成

| ファイル | 中身 |
|---|---|
| `index.html` | 本体（島・街・家・スパ・キャラクター・操作・BGM・CONFIG） |
| `library.js` | 3階建ての円い書庫（建物・本棚・らせん階段） |
| `lines.js` | 追加のセリフ |
| `data.js` | 本のデータ（`build_data.py` が作る） |
| `build_data.py` | `books/` から `data.js` を作るスクリプト |
| `books/` | サンプルの本（11冊・4棚） |
| `FEATURES.md` | 機能の一覧 |

設定の一部（カメラの向き・BGM のオン／オフ・操作説明の開閉・着替え）は、ブラウザの localStorage に保存されます。
