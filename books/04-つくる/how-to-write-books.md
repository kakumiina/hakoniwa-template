# 本の書き足し方

1. `books/` の中に棚のフォルダを作る（例: `05-料理`）。頭の番号は並び順にだけ使われます。
2. その中に Markdown の本を置く（例: `curry.md`）。
3. `python3 build_data.py` を実行すると、`data.js` が作り直されます。
4. ページを読み込み直すと、新しい棚と本が並びます。

## 書ける書式

- 見出し（`#`）、箇条書き（`-`）、**太字**、`コード`、コードブロック
- `[[ファイル名]]` で別の本へのリンク。つながった本どうしは夜空に金の線で結ばれます。
